# かずのせいしつラボ｜偶数・奇数と倍数・約数

小学5年生「偶数と奇数」「倍数と約数」の単元を、ゲーミフィケーションつきで
段階的にマスターできる学習アプリ。

## モジュール（単元の知識・技能を段階的に網羅）

| モジュール | 内容 |
|---|---|
| ぐうすう・きすうチェック | 一の位での判定 → 大きい数 → 0の性質 → 数列の穴うめ → **2×□／2×□＋1 の式表現** |
| ぐうすう・きすうのせいしつ | たし算・かけ算の結果予想・逆算・つまずきポイント・**わけの説明（並べかえ）** |
| 倍数みつけ隊 | □番目の倍数・判定・複数選択・**小さい順に書き出す**・範囲内の個数 |
| 公倍数・最小公倍数 | 求める・**書き出す**・選ぶ・文章題・**しきつめ（正方形をつくる）**・3数（発展）・**通分とのつながり（発展）** |
| 約数みつけ隊 | 判定・選ぶ・1から順に確認・**ペア探索**・**ぜんぶ書き出す**・個数 |
| 公約数・最大公約数 | 求める・**ベン図で整理**・選ぶ・文章題・**切り分け（正方形にする）**・3数（発展）・素数（発展）・**約分とのつながり（発展）** |
| エラーハンター | 0は奇数・1は素数・約数の1と自分自身の抜け・最大公約数と最小公倍数の混同など頻出の誤解を発見・修正・理由の言語化 |
| 本番テストモード | 表（知識・技能100点／20問）／裏（思考・判断・表現50点／5問。しきつめ・切り分けの幾何文脈が中心） |
| ボス戦：天空神 | インフェルノ解放で挑戦できるスペシャルステージ（Normal / Hard / GOD） |

## 回答UIと足場（scaffolding）

答えだけを入力させると、この単元の中核である「**もれなく列挙して共通部分を取る**」手続きが
飛ばされてしまう。そこで手続きそのものを画面上で再現する回答形式を用意している。

| 形式 | 用途 |
|---|---|
| 書き出し（list） | 「小さい順に3つ書きましょう」「約数を全部書きましょう」。候補は示さず自分で生成させる |
| ペア探索（pairs） | `1×18`, `2×9`, `3×6`… と約数をペアで探す。停止条件も体験できる |
| ベン図（venn） | 2数の約数を「左だけ・両方・右だけ」に振り分け、公約数の構造を可視化 |
| 多段階（steps） | 「①何をもとめる問題か → ②1辺は何cmか → ③何まいか」と立式の判断から段階的に |
| 並べかえ（sequence） | 「なぜ奇数＋奇数は偶数か」を、記述させずに論理の筋道として扱う |
| 倍数の帯（足場） | 2数の倍数をタップで出していき、共通が自動でハイライトされる |

足場は**習熟度に応じて自動で外れる**（連続ノーミス 0〜2＝常時表示／3〜4＝ヒントで任意表示／
5＝足場なし）。本番テストモードとボス戦では常に足場なし。
誤答時は、最大公約数と最小公倍数の取り違えなど**よくある誤りに特化した説明**を返す。

## ゲーミフィケーション

- きょうの目標リング（5/10/15/20問・タップで切替）
- 連続ノーミス記録・スキル別の熟達バー（5問連続ノーミスでMAX）
- ごほうびバッジ（累計・ノーミス・テスト得点・モジュール別デビュー／マスター・最終称号「【かずのせいしつ】神」）
- バッジ獲得率で解放される特別テーマ（極光25%・桜吹雪50%・インフェルノ75%・天空神100%）＋マトリックス
- おまかせモード（正答率にもとづく適応難易度。2問連続ノーミスでレベルアップ）
- ふくしゅうコーナー（正答率が低いスキルをホームで提案）
- やさしい効果音（Web Audio合成・設定でOFF可）とプロセス称賛メッセージ
- 学習のきろく（モジュール別クリア数・履歴・テストの答案詳細）

進捗・設定は localStorage に保存されます。

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`

## チェック

```bash
npm run lint            # 型チェック（tsc --noEmit）
npm run build           # 本番ビルド
npm run check:problems  # 問題ジェネレーターのプロパティテスト
```

`check:problems` は全ジェネレーター×全レベルを大量に生成し、答えの正しさに加えて
**教育的な妥当性**（最大公約数が1になる不自然な文章題が出ない／3数の問題で数が重複しない／
しきつめ問題が割り切れる／「○分おき」のような曖昧な表現を使わない 等）も検証する。
